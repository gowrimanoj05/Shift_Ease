# ShiftEase Frontend

React application for ShiftEase shift management system.

## Setup
```bash
npm install
```

## Environment Variables

Create a `.env` file:
```env
REACT_APP_API_URL=http://localhost:5000/api
```

## Running

Development:
```bash
npm start
```

Build:
```bash
npm run build
```

## Available Scripts

- `npm start` - Start development server
- `npm run build` - Build for production
- `npm test` - Run tests
- `npm run eject` - Eject from Create React App

## Features

- Interactive shift calendar
- AI-powered chatbot
- Shift swap requests
- Admin dashboard
- Responsive design
